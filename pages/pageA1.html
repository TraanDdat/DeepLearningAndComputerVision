1. Exploratory Data Analysis (EDA) & Dataset Split

  • Dataset Link:https://cave.cs.toronto.edu/kriz/cifar.html
  • Selected Dataset:The CIFAR-100 dataset
  • Split Configuration:
    • Total: 60000 Images
    • Train set: 45000 Images
    • Validation set: 5000 Images
    • Test set: 10000 Images
  • Description: This dataset is just like the CIFAR-10, except it has 100 classes containing 600 images each. There are 500 training images and 100 testing images per class. The 100 classes in the CIFAR-100 are grouped into 20 superclasses. Each image comes with a "fine" label (the class to which it belongs) and a "coarse" label (the superclass to which it belongs)

3. Experimental Protocol & Training Configuration Matrix

The experiments are set up consistently to compare the two architecture families ResNet-18 (CNN) and ViT-Small (Transformer) across weight initialization modes (From-SCratch) and freeze levels based on the pretrained model:

  • Environment: PyTorch, GPU NVIDIA RTX 3500
  • Pretrained model: Resnet18-Pytorch-ImageNet, ViT-Small (PyTorch)
  • Optimizer: AdamWlr = 0.0003, betas = (0.9, 0.999), weight_decay = 1e-3
  • Scheduler: ReduceLROnPlateau:mode = "min", factor = 0.5, patience = 5, min_lr = 1e-6
  • Epochs:60
Ver. Model Initialize weights Training Strategy Freeze Level Details
1 ResNet-18 / ViT-Small Kaiming Method From-Scratch Unfreeze 100% of parameters (Train from scratch).
2 ResNet-18 / ViT-Small Pretrained Freeze All Of Backbone Freeze the entire Backbone, only train the Linear Classifier Head.
3 ResNet-18 / ViT-Small Pretrained Freeze Partial Backbone Partial freeze (Freeze Layers First Convolution, First Batch Normalization, Layer 1 of ResNet or the first 6 Transformer Blocks of ViT-Small).
4 ResNet-18 / ViT-Small Pretrained Full Fine-tune Unfreeze the entire network and fine-tune with a small Learning Rate.
